# Estudos de C# - Codédex

Este repositório foi criado para organizar os exercícios, anotações e códigos do curso de C# do Codédex.

## Como estudar comigo (seu professor de IA)
1. **Crie seus arquivos de código** nesta pasta (por exemplo, `Exercicio01.cs`, `BabyNames.cs`, etc.).
2. **Traga suas dúvidas**: Quando um exercício estiver difícil ou você não entender um erro, me mostre o código ou descreva a lógica.
3. **Sem respostas prontas**: Eu não vou te dar a resposta de bandeja! Vou te fazer perguntas, dar dicas e explicar conceitos para que você descubra a solução por si mesmo.

Bons estudos! 🎮🚀
